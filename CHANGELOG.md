# Changelog

## Summary of Changes: February 1 – March 26, 2026

This document summarizes all notable changes made to the Spargine 10 repository between February 1, 2026 and March 26, 2026.

---

## [2026.10.3.1] – March 1, 2026

### Documentation & Metadata
- Updated all project and documentation files to version **2026.10.3.1**.
- Refreshed "Generated by Spargine" timestamps and README version badges.
- Removed `FastFormat` from Extensions info docs (method was removed in February).
- Marked `HasWhitespace` and multiple Core methods as `BenchmarkStatus.Completed`.
- Added new benchmark classes and refreshed benchmark results.

---

## [2026.10.2.15] – February 15–26, 2026

### New Features

#### Collections
- **`ObservableList<T>`** – Refactored for improved event notification correctness. `PropertyChanging`/`Changed` events are now raised only when actual changes occur. `AddRange` and `RemoveRange` collect items before mutation for atomicity. Replaced `FastLongCount()` with `Count` for efficiency.
- **`ReadOnlyCollectionExtensions`** – Added `TryGetValue` and `GetValueOrDefault` extension methods.

#### Enumerations
- **`EnumExtensions`** – Added advanced enum extension methods: `ToInt32`, `ToInt64`, `GetAttribute`, `GetDisplayName`, `GetSetFlags`, `FlagCount`, `Next`, and `Previous`.
- **`NumericFormat`** – Made class `sealed` and expanded with new numeric format constants: `Binary`, `CurrencyWholeNumber`, `FourDecimalPlaces`, `HexadecimalLower`, `OneDecimalPlace`, `PercentWholeNumber`, `TwoDecimalPlaces`, and `WholeNumber`.

#### Character Extensions
- **`CharacterExtensions`** – Refactored to use properties for ASCII checks; added new fast classification and conversion methods. Added `IsUnicodeDigit`. Removed/consolidated `IsAsciiDigit`, `IsAsciiLetter`, `IsAsciiLetterOrDigit`, `IsAscii`, `IsAsciiLower`.

#### String Extensions
- **`FastFormat`** – Added efficient string formatting using `stackalloc` and pooled `StringBuilder` (introduced Feb 14, subsequently **removed** Feb 24 after analysis – see Removals below).

#### Performance
- **`PerformanceStopwatch`** – Added three new static methods: `GetElapsedTime(long)`, `GetElapsedTime(long, long)`, and `GetTimeStamp()`.
- Enabled **server garbage collection** (`<ServerGarbageCollection>true</ServerGarbageCollection>`) in the benchmarking project for improved performance.

#### StringBuilder
- **`ClearSetCapacity(bufferSize)`** – Replaced separate `Clear()` + `EnsureCapacity()` calls on pooled `StringBuilder` instances with a single streamlined method.

### Refactoring & Improvements
- Removed unnecessary null-forgiving operators (`!`) throughout the codebase, improving null-safety and code clarity.
- Added `DebuggerDisplay` to `ExceptionMetadata`.
- Added `Preserve` attribute to `ServiceProxy<T>` constructor.
- `EnumItem<T>` sealed for improved encapsulation.
- Refactored `App.GenerateDiagnosticReport` to single-line output.
- Minor code cleanup across benchmark methods to consume results via `this.Consume(...)` per BenchmarkDotNet best practices, preventing dead code elimination.

### Removals
- **`FastFormat`** extension method and its benchmark were **removed** (Feb 24) after performance analysis. String formatting benchmarks now use only `string.Format`.
- Removed obsolete `RunBenchmarks` overload without `saveResults` parameter.
- Removed character-level ASCII tests from `StringExtensionsTests` (moved to `CharacterExtensionsTests`).

### Unit Tests Added
- `CharacterExtensionsTests` – Comprehensive tests for all character extension scenarios.
- `ClockTests` – Full coverage of all `Clock` properties and methods.
- `FastContainsTests` – Coverage for various collection types, comparers, and edge cases.
- `GenerateCoordinateCollection<T>` tests – Count, default/invalid handling, read-only return type.
- `App.ClearAppState` / `App.RemoveAppState` tests.
- `EnumValue` constructor and `JsonSerialization.LoadCollectionFromJson(FileInfo, int)` tests.
- `AutoDefaultDictionary` benchmark tests.

### Benchmarks Added
- `AutoDefaultDictionaryCollectionBenchmark` – Tests `AddOrUpdate`, `ContainsValue`, `GetOrAdd`, `GetValueOrDefault`, `ToImmutableDictionary`, `TryAdd`, `TryUpdate`.
- `CharacterExtensionsBenchmark` – Performance tests for all character extension methods and properties.
- `ObservableListBenchmark` – Tests for all major `ObservableList<T>` operations.
- `DistinctBlockingCollectionBenchmark` – BenchmarkDotNet tests for all major public methods.
- `DistinctConcurrentBagBenchmark` – BenchmarkDotNet tests for all major public methods.
- `ConcurrentDictionaryBenchmark` – New concurrent collection benchmarks.

## [2026.10.2.14] – February 14, 2026

### New Features
- **`FastContains`** – New high-performance `IEnumerable<T>` extension method with optional `IComparer<T>` support. Uses `HashSet<T>` fast lookup with default comparer, binary search for `List<T>` and arrays, and falls back to linear search for other enumerables.

### Refactoring
- Optimized `List<T>` extension methods; removed redundant explicit null checks.
- Improved XML documentation for `IsEqualTo` and other extension methods.

### Dependency Updates
- Downgraded `Microsoft.Extensions.ObjectPool` to 10.0.0 in Core and Extensions.
- Adjusted `System.Management` and `System.ServiceProcess.ServiceController` to 10.0.2.
- Adjusted `Microsoft.AspNetCore.Components` and `Microsoft.EntityFrameworkCore.SqlServer` to 10.0.2 in Extensions.Tests.

---

## [2026.10.2.13] – February 13, 2026

### New Features
- **`Clock`** – Significantly enhanced with advanced date/time properties and methods:
  - New properties: day, quarter, leap year, Unix timestamp calculations (local and UTC).
  - `LocalTime` and `UtcTime` now return `DateTimeOffset` for improved time zone accuracy.
  - New methods: days remaining in month/year, weekday/weekend checks.
  - Renamed `Clock.Today` → **`Clock.TodayMidnight`** for clarity.

### Refactoring
- Replaced hardcoded array mutation error in `CollectionExtensions` with a localized resource string.
- Enhanced XML documentation for `HashPassword` and `SplitLines` in `StringExtensions`.

### Dependency Updates
- Added **`Microsoft.Extensions.Configuration`** (v10.0.0) to multiple projects.
- Downgraded `Microsoft.Extensions.Caching.Memory` and `Logging.Abstractions` to v10.0.0 in Core.

## [2026.10.2.1] – February 1–12, 2026

### New Features

#### App State Management
- **`App.ClearAppState`** – New method to clear all application state.
- **`App.RemoveAppState`** – New method to remove a specific application state entry.
- **`App.GetAppState`** – Added `defaultValue` parameter for safe retrieval with fallback.

#### Thread Safety
- **`SimpleResult<T>`** – Refactored for thread safety. Now uses `DistinctConcurrentBag` for unique exceptions and messages. Added `ILogger` support.

#### ULID
- Fixed ULID timestamp encoding to always use **big-endian** for correct lexicographic sorting. Updated `GetTimeStamp` to decode in big-endian. Improved sort test with increased sleep interval.

#### ServiceProxy
- Refactored **`ServiceProxy<T>`** and added `global.json` for SDK version pinning.

#### Benchmarking
- Enhanced `BenchmarkHelper` with timing summary and improved logging/docs.
- Added `RunBenchmarks` overload for simplified invocation.

### Fixes
- **`FileProcessor.DeleteFiles`** – Added null check at method entry; returns `0` if `files` parameter is null, preventing potential null reference exceptions.
- **`LinqExtensions`** – Updated `Information` attribute; removed `ModifiedBy` parameter.

### Dependency Updates
- Updated **`Microsoft.Extensions.Logging`** to **10.0.3**.
- Updated MSTest and Application Insights package versions.
- Updated NuGet packages (`coverlet.collector`, `SourceLink.GitHub` to 10.0.102, etc.).

### Documentation
- Updated README to use Markdown syntax for image links (replacing HTML).
- Included **`LICENSE.txt`** in all NuGet packages at root level.
- Updated `PackageProjectUrl` to shortened Spargine link.
- Improved XML documentation throughout: `DictionaryExtensions`, `PasswordHasher`, `Enumeration`, `CollectionExtensions`, `DateTimeExtensions`, `EnumerableExtensions`.
- Refactored `DateTimeExtensions` ISO week/year methods.
